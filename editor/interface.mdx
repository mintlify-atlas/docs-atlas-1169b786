The SkillTanki Editor is a browser-based level editor that loads the full set of game prop libraries directly — no installation or account required. The layout follows the original 2010 AIR editor closely: a menu bar and toolbar run across the top, the main 3D workspace fills the centre, a preview pane and prop palette occupy the right panel, and a status bar sits at the bottom of the page.

<Note>
  The editor requires a desktop browser. Mobile and tablet devices are not supported — mouse controls (middle-click pan, Alt+middle orbit, scroll-wheel zoom) and the keyboard shortcut set assume a full desktop input setup.
</Note>

## The Workspace Viewport

The workspace is a full 3D PlayCanvas view rendered on a `<canvas>` element. It fills all available horizontal space and is the primary surface for placing, selecting, and moving props. The viewport uses a Z-up sim-space coordinate system (1 m = 100 sim units); the underlying PlayCanvas scene is Y-up and the conversion is handled transparently by a `simRoot` entity.

A reference grid is drawn in the XY plane. It can be toggled with the **▦** toolbar button or via **Option → Show grid**.

When a prop is attached to the cursor, the cursor ghost turns **green** when the target cell is free and **red** when it is already occupied — provided snap mode is active.

## The Props Accordion

The Props accordion on the right panel lists every prop in the currently selected library, grouped by category. Clicking a prop cell loads that prop onto the cursor so you can place it in the workspace.

<CardGroup cols={2}>
  <Card title="Library Combo" icon="list">
    A dropdown at the top of the palette that switches between the 11 shipped prop libraries: **Buildings**, **Builds**, **Castle**, **Complex Build**, **Elements**, **Land**, **Landscape**, **kahgel**, **kariz**, **yonje**, and **zamin**. All libraries are loaded at startup, so switching is instant.
  </Card>
  <Card title="Prop Cells" icon="grid-2">
    Each cell shows a rendered icon of the prop (captured via an off-screen preview pass) and its name. Clicking a cell sticks the prop to the cursor ready for placement. The prop palette also includes a synthetic **Functional** library containing spawn points, bonus regions, and CTF flags.
  </Card>
</CardGroup>

The **"Selecting prop"** combo above the palette filters which kinds of props are selectable in the viewport: **All**, **Tile**, **Sprite**, or **Bonus + Spawn**. The filter does not affect which props are visible, only which ones respond to picking.

## The Preview Pane

The preview pane sits above the Props accordion and shows a spinning 3D render of the currently active prop. It updates in these situations:

- You hover over or click a cell in the Props accordion.
- You select a prop already placed in the workspace.
- A prop is attached to the cursor.

The render is generated by a dedicated off-screen camera. Billboard sprites (such as trees) are shown in their flat orientation. Functional props (spawn points, bonus regions, flags) are shown as procedural gizmos because they carry no `.3ds` mesh.

## The Property Panel (Texture Variants)

When a placed tile is selected in the workspace, the **Textures** panel appears at the top of the right panel (toggled with the **◉** toolbar button). It lists every named texture variant that the prop's `.3ds` entry declares. Clicking a variant applies it immediately to all selected tiles and records the change in the undo journal.

<Accordion title="Opening the texture panel">
  1. Select one or more tiles in the workspace.
  2. Click the **◉** button in the toolbar, or choose a tile — the panel slides in automatically if it was already open.
  3. Click any variant swatch to apply that texture.
  4. Press **F** to mirror the texture horizontally.
</Accordion>

Sprites and functional props (spawn, bonus, flag) have no texture panel entry; the panel is hidden when only those kinds are selected.

## The Toolbar

The six toolbar buttons sit immediately below the menu bar.

| Button | ID | Toggle? | Action |
|---|---|---|---|
| **⊓** | `snap` | Yes (default on) | Enable snap mode — props are seated on the 5 m × 5 m × 3 m occupancy grid |
| **◳** | `view` | Yes (default off) | Collision view — draws the collision primitives (boxes, planes, triangles) over every tile |
| **▦** | `grid` | Yes (default on) | Show or hide the XY reference grid |
| **◉** | `textures` | Yes (default off) | Show or hide the texture-variant property panel |
| **◌** | `hideSelected` | No | Hide all currently selected props; hidden props cannot be picked |
| **👁** | `showAll` | No | Make every hidden prop visible again |

Toolbar state is also reachable from the **Option** menu (Snap, Show grid, Normal, Collision boxes).

## The Menu Bar

<Accordion title="File menu">
| Item | Shortcut | Action |
|---|---|---|
| New | `Ctrl+N` | Clears the scene and resets the map name to "untitled" |
| Open… | `Ctrl+O` | Opens a `.lvl` file (the editor's binary format) via a browser file picker |
| Save | `Ctrl+S` | Downloads the current map as a `.lvl` file |
| Save as… | `Ctrl+Alt+S` | Same as Save |
| Export to Tanks | `Ctrl+T` | Exports the map as a Tanks XML `.xml` file, readable by the game |
| Import from Tanks | `Ctrl+I` | Imports a Tanks XML `.xml` file |
</Accordion>

<Accordion title="Edit menu">
| Item | Shortcut | Action |
|---|---|---|
| Undo | `Ctrl+Z` | Reverses the last operation (add, delete, move, rotate, copy, texture change) |
| Redo | `Ctrl+Y` | Re-applies the last undone operation |
| Clear | `Ctrl+Alt+C` | Removes all props without adding to the undo journal |
</Accordion>

<Accordion title="Option menu">
| Item | Action |
|---|---|
| Unlock | Sets multiple-prop mode to 0 — no occupancy conflict checking when moving |
| Lock group | Sets multiple-prop mode to 1 — only props of the same group conflict (default) |
| Lock | Sets multiple-prop mode to 2 — all props in a cell conflict |
| Normal | Switches to the normal mesh view |
| Collision boxes | Switches to the collision-primitive overlay |
| Snap | Toggles snap mode (same as the toolbar ⊓ button) |
| Show grid | Toggles the reference grid (same as the toolbar ▦ button) |
</Accordion>

On macOS, `Cmd` stands in for `Ctrl` in all shortcuts. Bindings compare key codes rather than characters, so they work correctly on non-Latin keyboard layouts.

## The Status Bar

The status bar at the bottom of the editor displays a single line of text that reflects the most recent operation. Common messages include:

- `Loading libraries…` — startup loading phase
- `Cursor: <group> / <name> — Space to place, Esc to drop` — a prop is attached to the cursor
- `<map name>: <n> props` — a map finished loading, with a count of placed props
- `This location is occupied.` — snap conflict detected after a drag
- `Snap on / Snap off` — snap mode toggled
- `Saved <filename> (<n> bytes)` — a `.lvl` file was downloaded
- `Exported <filename>` — a Tanks XML file was downloaded
